APG · Menu Button

Menu button

Real focus moves into the menu here — the opposite of the combobox, where focus stays in the input. There is no text field to keep it in.

Last action: none yet

What to check. Type d repeatedly in the first menu — it cycles Duplicate → Delete → Duplicate, rather than searching for "dd". Checkbox items keep the menu open so several can be set in one visit; everything else closes and returns focus to the button.

Notes

Do not use this for site navigation. A <nav> full of links marked role="menuitem" is the single most common misuse of the role: it strips every link affordance a screen reader user relies on — no "link" announcement, no link list in the rotor, no open-in-new-tab expectation. role="menu" is a promise that this is a list of actions with menu keyboard behaviour. Navigation is a list of links.

Checkbox and radio items carry their state in aria-checked, and the tick is drawn from that attribute in CSS — so the visual state cannot drift from the announced state.

Built against the ARIA Authoring Practices Guide.
Every pattern here is verified with the keyboard and with VoiceOver, not just with a linter.
